# Korneliusz Musiał — Portfolio Website

**A static personal portfolio built with HTML, CSS and JavaScript.**

The current site lives in `index.html` and includes its existing visual assets. This repository contains the presentation layer for project case studies; the project selection is documented in [the GitHub profile repository](https://github.com/Korniszon99/Korniszon99).

## Preview locally

```bash
git clone https://github.com/Korniszon99/korneliusz.musial.git
cd korneliusz.musial
python -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000/>. No Node build pipeline is required. External fonts, map libraries or other CDN assets used by the page need network access.
